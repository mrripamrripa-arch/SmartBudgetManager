# SmartBudgetManager
A project for managing Budget
Screenshot requirement
Students must include at least:
 One annotated screenshot of the Transactions sheet
 One annotated screenshot of the Dashboard
 One screenshot showing the budget warning or conditional formatting
 One chart screenshot, if a chart exists
Each visual must have:
 A figure number, for example: Figure 1. Transactions worksheet
 A concise caption
 Arrows, labels, circles, or callouts where necessary.
